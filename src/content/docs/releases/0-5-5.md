Vast **0.5.5** is the current Direct Windows x64 release, published **2026-10-24**. The previous Direct release is [0.5.0](/releases/0-5-0/). Download the [official release](https://github.com/vstxx/vast-public/releases/tag/v0.5.5) or follow [Installation & Updates](/get-started/installation-and-updates/).

0.5.4 was published earlier the same day and withdrawn within hours: after its automatic update, Vast could keep running without showing a window. 0.5.5 contains everything from 0.5.4 plus that fix.

## What's new

- Browse the Chrome Web Store inside Vast. On an extension's listing, Vast's own **Install in Vast** button opens the same review flow as other installs; the store page gets no special access. Pasting a listing URL into Extensions still works. See [Extensions](/extensions/extensions/).
- **Visual Profiles** save the whole Appearance page under a name, switch between looks, and import or export them as `.vastvisual` files. They replace the Appearance live preview. See [Appearance Reference](/customization/appearance-reference/#visual-profiles).
- Calling apps such as Google Meet, Zoom, and Microsoft Teams can ask for the camera and microphone. **Allow once** lasts for the visit, so the site sees your devices without asking again. See [Site Data & Permissions](/privacy/site-data-and-permissions/).
- New appearance controls: **Background blur** for dialogs, Settings, and the command palette; **Transparency** and **Frost** for surfaces that float over pages. The dark theme uses neutral black and gray, and the accent color drives the interface highlight color.
- Horizontal tabs no longer hide behind an overflow menu: the tab strip scrolls once tabs reach their minimum width, and **All tabs** searches them while it overflows.

## Improvements and fixes

- Vast always shows its window after an automatic update, and opening Vast while it is already running brings its window forward.
- Runs on a newer patched browser engine: Electron 45 with Chromium 156.
- Faster startup with many tabs or extensions: the window opens while extensions are restored, and pages wait for them only briefly.
- Smoother tab closing and reordering, Settings and command palette scrolling, and side panel lists.
- Custom New Tab wallpapers display at any image size.
- Address bar suggestions open only after you type.
- The vertical sidebar's compact view uses uniform tiles, and clicking the active workspace collapses the workspace list.
- Deleting a note asks for confirmation. The notes, bookmarks, and history panel is now called the side panel.
- The link preview was removed from the context menu.
- The Extensions Hub lists every extension on the website.

## Important upgrade information

Installed **0.5.0** and **0.5.4** Direct copies update automatically through `stable-v2.yml`. An update installs only after every Vast process has closed; otherwise it waits and changes nothing. If 0.5.4 started without a window on your PC, restart Windows or end **Vast** in Task Manager, then open Vast to update.

The legacy `latest.yml` remains pinned to **0.4.2**: close a 0.4.2 installation and run the 0.5.5 setup or standalone updater once. The updater requires an existing Direct installation. Portable users replace their Portable executable; Store users update through Microsoft Store.

Microsoft Store availability is independent of Direct publication. **Store 0.5.5 availability is unconfirmed.**

## Known limitations

- Manifest V2 extensions that block web requests (`webRequestBlocking`) stay installed but are not loaded, because on the new browser engine they stop pages from loading. Use the Manifest V3 version where one exists. Adblocker for Vast is not affected.
- Installing from the Chrome Web Store does not mean every Chrome extension works in Vast.
- Extensions are unavailable in private and ephemeral workspaces.
- Bitwarden, Proton Pass, and iCloud Passwords have smoke-test evidence, not certification of every website or vault workflow.
- Persistent isolated workspaces separate website partitions; bookmarks and history remain browser-level state. Workspace isolation is not a guarantee of anonymity or fingerprint separation.

Vast-owned desktop source is **GPL-3.0-only**. Third-party code and assets retain their own licenses.
