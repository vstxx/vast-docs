title: "Vast 0.4.2 Release Notes"
description: "Windows scroll-performance hotfix, verified direct downloads, and update guidance."
---

Vast **0.4.2** was the previous direct Windows x64 release. It fixes delayed scrolling on heavy websites, including Gmail and ChatGPT, caused by a non-passive wheel listener in the guest-page preload. Use the [current 0.4.3 release](/releases/0-4-3/) for new downloads, or read the [installation guide](/get-started/installation-and-updates/) for the one-time manual upgrade from 0.4.2.

The guest-page wheel listener is now passive. Vast's custom Ctrl/Meta+wheel zoom forwarding inside website webviews was removed; keyboard and browser UI zoom controls are unchanged. Electron 44.3.0, ECE 4.9.0, and the password-manager extensions are unchanged from 0.4.1.

The direct installer, Portable executable, and standalone updater are **intentionally unsigned**. Windows may show Unknown publisher or SmartScreen warnings. Compare a download with the release's SHA-256/SHA-512 checksums before running it.

The isolated release checks covered a clean installation, a real 0.4.1 → 0.4.2 updater upgrade with profile preservation, an isolated automatic detection/download canary, and a manual browser check after restart. The exhaustive formal password-manager acceptance gate was not rerun for this narrow hotfix; no claim is made about every site or vault workflow.

The standalone updater is only for existing direct installations. Portable needs the newer Portable executable. Microsoft Store updates are managed by Microsoft Store and follow a separate certification and rollout.

See [0.4.1 release notes](/releases/0-4-1/) for the previous feature release and [Installation & Updates](/get-started/installation-and-updates/) for package and profile guidance.
