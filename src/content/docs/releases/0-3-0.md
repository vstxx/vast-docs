Vast **0.3.0** was published for Windows x64 on **12 September 2026**. These notes describe changes since **0.2.7**. The desktop runtime remains Electron 44.1.0.

Use the [installation and update guide](/get-started/installation-and-updates/) to choose the correct package. The [public release](https://github.com/vstxx/vast-public/releases/tag/v0.3.0) includes the installer, Portable, standalone updater, full update ZIP, checksums, manifests, and FFmpeg source.

:::caution[Choose the correct update channel]
The direct Windows binaries are intentionally unsigned. The standalone updater does not update Microsoft Store/MSIX or Portable installations. Store updates require separate Store certification and availability; publication on GitHub does not update the Store listing.
:::

## Downloads and workspace sessions

- Fixed downloads that saved correctly but never appeared in progress notifications or sidebar history, including sessions created by extensions during startup.
- Connected download tracking to shared, isolated persistent, and temporary workspace sessions, with duplicate-safe setup when a webview attaches.
- Restored active download progress after reloading the browser interface and kept simultaneous downloads independently visible.
- Persisted download start and completion before subsequent security-scan results, so a slow scan no longer delays completed history.
- Retry now uses the original workspace session, preserving its cookie and authentication context when that session is available.
- Kept temporary-session download records out of durable history. Files explicitly saved to disk still remain on disk.

## Global corner radius and appearance

- Made Corner radius a continuous global control across the 6–36 px range, with proportional shapes for controls, cards, panels, menus, and dialogs.
- Applied the same radius system to browser chrome, tabs, workspace controls, Settings, internal pages, notifications, PDF controls, and password autofill surfaces.
- Applied the persisted radius during startup and window creation. True circles, decorative shapes, and intentional docked edges retain their geometry.
- Reduced excessive glow and shadow treatment in Settings, particularly in Dim mode, and corrected inconsistent Dim backgrounds in Notes and adjacent panels.

## Navigation, Purist, and menus

- Fixed pointer handling in the experimental Purist omnibar so the address bar and its buttons respond to clicks.
- Corrected More Tabs overflow placement so the searchable hidden-tab menu does not collide with the address bar and neighboring controls.
- Repaired browser context-menu routing for navigation, selection copying, page actions, notes, Reading List, printing, muting, and inspection where supported.
- Added packaged menu coverage for web pages, internal surfaces, and tab lifecycle transitions.

## Settings and privacy

- Reorganized Privacy settings into consistent half-width controls, with long exception inputs grouped in full-width rows below.
- Changed Set browser as default to use the normal Settings button style while keeping Windows in control of default-app selection.
- Removed the native ad-blocking engine, filter-list settings, and browser ad-blocker shortcut. Install the optional Adblocker for Vast extension for filter-list and cosmetic blocking.
- Retained built-in common-tracker protection, link cleaning, cookie controls, fingerprinting protection, WebRTC policy, and workspace isolation.

## Background updates and recovery

- Completed background update downloading for eligible installed direct builds, with verified installer metadata and a durable next-launch handoff.
- Bound prepared updates to the original installation and profile, preserving custom install paths and separating independent installations.
- Kept the running browser available if the update helper cannot accept the handoff, and bounded failed installation retries instead of repeatedly trapping startup.
- Protected active sessions by waiting for the old browser process before replacing application files.
- Kept Microsoft Store updates managed by Microsoft Store. Portable and unpacked copies do not run the installed-browser automatic update path.

## Windows installation and Store packaging

- Unified the actual NSIS installer include so PDF registration and uninstall cleanup are included in the packaged installer.
- Registered Vast as an available PDF Open with handler without taking over the current PDF default or changing Windows UserChoice.
- Verified that uninstall removes Vast-owned registrations while preserving generic PDF, HTTP, HTTPS, and user-selected associations.
- Added transparent, unplated Windows taskbar icons at standard target sizes without extra padding, plus package checks that require them.
- Separated browser version 0.3.0 from the configurable Store package version. Store availability follows its separate certification and rollout.

## Performance and persistence

- Preserved lazy loading of the browser stage, Settings, Command Palette, Side Panel, and Smart Unload.
- Kept inactive restored tabs discarded until needed, together with tab/sidebar memoization, content visibility, and stable webview event bindings.
- Kept high-frequency download progress out of general renderer autosave; download persistence remains owned by the main process.
- Retained queued and deduplicated writes, consolidated persistence, bounded rolling backups, cached request-policy derivation, and asynchronous diagnostics writes.
- Rechecked the obfuscated production build and existing JavaScript budgets without changing the Electron 44.1.0 runtime or browser-view architecture.

## Release verification

- Updated compatible dependencies and overrides so the root and Relay dependency audits pass without high or critical findings.
- Expanded download lifecycle, radius, updater, installer, menu, extension, and release-integrity regression coverage.
- Verified the real 0.2.7-to-0.3.0 upgrade and Windows installation lifecycle, along with public source and secret-scanning checks.
- Published the same verified candidate bytes with SHA-256/SHA-512 lists, source provenance, update metadata, and FFmpeg corresponding source.

## After updating

Existing profile data and preferences are retained through normal migrations. Reopen the browser and confirm version 0.3.0 in Settings. If you used native ad-block lists, install and configure [Adblocker for Vast](/extensions/adblocker-for-vast/); old native filter settings do not automatically configure the extension.

See [Troubleshooting](/developers/troubleshooting/) for download, update, and workspace issues. Back up important data before switching distribution channels or moving an installation.
