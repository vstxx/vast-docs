Vast **0.4.0** is the Windows x64 direct release after **0.3.0**. It uses Electron 44.3.0 with a source-controlled compatibility patchset.

Download the [installer, Portable build, or standalone updater](https://github.com/vstxx/vast-public/releases/tag/v0.4.0). The release also provides checksums, update metadata, and corresponding source. Read [Installation & Updates](/get-started/installation-and-updates/) before changing distribution channels.

:::caution[Unsigned direct release]
The direct installer, Portable build, and standalone updater are intentionally unsigned. Windows may show **Unknown publisher** or a SmartScreen warning. Verify the published checksum before running a download. The direct updater must not be used for Microsoft Store/MSIX or Portable installations; a Store update requires a separate Store submission and rollout.
:::

## Extensions

- The Extension Hub can install unmodified Bitwarden and Proton Pass packages with their upstream extension IDs. Their Hub listings identify the upstream publishers without claiming publisher verification or partnership.
- iCloud Passwords is installed from Apple's upstream Chrome Web Store extension, using its original ID. Vast does not host or repackage Apple's extension. Apple authorization and Windows iCloud integration still depend on Apple's software and account state.
- The browser compatibility runtime uses pinned Electron and ECE patches and fails closed if its approved runtime cannot be initialized. Extension popups can be resized in width and height.
- The updated standalone Adblocker for Vast extension is available through the Hub. Vast's built-in common-tracker protection remains separate from extension blocking.

Compatibility testing used controlled accounts and fixtures. The exhaustive formal password-manager gate is not complete; this release does not claim that every password-manager workflow or website has been certified. Do not send vault contents when reporting a defect.

## Interface and release integrity

- Added **Clean toolbar icons**, which removes outlined toolbar button backgrounds and slightly enlarges the glyphs when enabled.
- Aligned Settings text sizing and corrected misleading partial-compatibility status when the approved extension runtime is active.
- Kept the direct release on the intentional unsigned route, with release provenance tied to the exact Vast commit, ECE patch, Electron patchset, and approved binary fingerprint.

## After updating

Normal direct upgrades preserve the existing Vast profile and installed extensions. Verify version **0.4.0** in Settings, then check that your extensions remain installed and your vaults are unlocked or can be unlocked normally. Do not clear a password-manager profile to troubleshoot an extension without first backing up important data.

If the Microsoft Store still offers an older Vast build, wait for its independent certification and rollout. The GitHub release does not update a Store installation.
