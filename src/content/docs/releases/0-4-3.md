Vast **0.4.3** is the current direct Windows x64 release. Download the [verified public release](https://github.com/vstxx/vast-public/releases/tag/v0.4.3) or use the [installation guide](/get-started/installation-and-updates/).

## What changed

- Reduced avoidable work during startup, first page load, Settings, and sidebar updates. Background tab retention and manual sleep handling were adjusted to avoid unnecessary reloads.
- Improved website scrolling, including nested Purist scrolling, and fixed the clipped opening logo.
- Updated renderer styling to Tailwind CSS 4.3.3 while preserving the existing interface.
- Updated the pinned Electron 44.3.0 compatibility runtime and retained ECE 4.9.0 extension support.
- Isolated Microsoft Store profile data from direct installations and tightened browser-import and managed-extension path handling.

## Updating an existing 0.4.2 installation

The 0.4.2 automatic updater can download an update but fail while handing the installer off at the next startup. To avoid sending users into that failing transition, the legacy `latest.yml` feed remains pinned to 0.4.2. **Close Vast, then run the [0.4.3 installer](https://github.com/vstxx/vast-public/releases/download/v0.4.3/Vast-Setup-0.4.3.exe) or [0.4.3 standalone updater](https://github.com/vstxx/vast-public/releases/download/v0.4.3/VastUpdater-0.4.3.exe) once.** The direct-install profile is preserved. Installed 0.4.3 and later builds use a new update feed for subsequent automatic updates.

The standalone updater is for an existing **direct installation** only. Portable users need the new Portable executable. Microsoft Store installations use a separate package and Store-managed updates.

## Distribution and verification

The direct installer, Portable executable, and standalone updater are **intentionally unsigned**. Windows may show Unknown publisher or SmartScreen warnings. Compare your download with the release's [SHA-256/SHA-512 checksums](https://github.com/vstxx/vast-public/releases/tag/v0.4.3) before running it.

Release checks included clean installation, a standalone 0.4.2 → 0.4.3 upgrade with profile preservation, checks that 0.4.2 remains on its legacy feed, and a 0.4.3 updater canary for the new feed. A manual canary covered browsing and basic Bitwarden, Proton Pass, and iCloud use. The exhaustive formal password-manager acceptance matrix remains open; every website and vault workflow is not certified.
