Vast **0.5.0** is the current Direct Windows x64 release, published **2026-10-14**. The previous Direct release is [0.4.3](/releases/0-4-3/). Download the [official release](https://github.com/vstxx/vast-public/releases/tag/v0.5.0) or follow [Installation & Updates](/get-started/installation-and-updates/).

## What changed

- The built-in Password Manager and `vast://passwords` are retired. Use external extensions; Bitwarden, Proton Pass, and iCloud Passwords have smoke-test evidence, not certification of every site or vault workflow.
- Direct Chrome Web Store listing-URL installation is available. Full Chrome Web Store navigation remains guarded in packaged 0.5.0.
- Fresh onboarding selects individual Labs through `DEFAULT_DATA`; the generic `DEFAULT_SETTINGS` fallback remains fail closed. The global `labs.enabled` field does not gate individual features.
- Persistent isolated workspaces have distinct persistent browser partitions; private/ephemeral workspaces have nonpersistent partitions; shared workspaces use the default partition. Bookmarks and history remain browser-level state. Extensions are unavailable in private/ephemeral workspaces.
- Vast-owned desktop source is **GPL-3.0-only**. Third-party code and assets retain their own licenses.

## Updating

Installed **0.4.3** Direct copies can update automatically through `stable-v2.yml`. The legacy `latest.yml` remains pinned to **0.4.2**: close a 0.4.2 installation and run the 0.5.0 setup or standalone updater once. The updater requires an existing Direct installation. Portable users replace their Portable executable; Store users update through Microsoft Store.

Microsoft Store availability is independent of Direct publication. **Store 0.5.0 availability is unconfirmed.**
