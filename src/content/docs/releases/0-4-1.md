Vast **0.4.1** is the current direct Windows x64 release. **0.4.0 was withdrawn**; the previous supported direct release was 0.3.0. Download only the [verified public 0.4.1 release](https://github.com/vstxx/vast-public/releases/tag/v0.4.1) or use the [installation guide](/get-started/installation-and-updates/).

## Highlights

- Added a source-controlled Electron 44.3.0 / ECE 4.9.0 Chrome-extension compatibility runtime and a unified Extension Hub.
- Added Hub installation for upstream Bitwarden and Proton Pass packages, preserving their extension IDs. iCloud Passwords uses Apple's upstream Chrome Web Store package and original ID; Vast does not host or repackage it.
- Improved extension popup sizing and optional Adblocker for Vast integration. Adblocker is not installed by default.
- Added Clean toolbar icons, refreshed Settings and onboarding, and repaired import, network, IPC and release hardening defects.
- Bound the release binary to exact source, Electron/ECE patches, FFmpeg source, hashes and published provenance.

## Important limitations

The direct installer, Portable executable and standalone updater are **intentionally unsigned**. Windows may show Unknown publisher or SmartScreen warnings. Compare the published SHA-256 or SHA-512 checksums before opening a download.

Password-manager compatibility was tested with controlled accounts and fixtures, but the exhaustive formal gate remains open. This release does not certify every site or workflow. Do not send vault contents or credentials with a bug report. Apple and other upstream extensions retain their own publishers and licenses; their Hub entries do not imply a partnership or endorsement.

The standalone updater is only for an existing direct installation. Portable requires a new Portable executable; Microsoft Store updates remain Store-managed and follow a separate certification and rollout. Normal direct updates are designed to preserve profiles and extensions, but back up important data before changing distribution channels.

For detailed installation, verification and update instructions, see [Installation & Updates](/get-started/installation-and-updates/). Historical [0.3.0 release notes](/releases/0-3-0/) remain available.
