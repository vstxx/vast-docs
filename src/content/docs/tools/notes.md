---
title: Notes
description: Create, search, organize, preview, and export local Markdown notes in Vast.
---

Notes is Vast's local notebook. Open it from the Command Palette, the side panel, or `vast://notes`.

## Create and edit notes

Create a blank note or start a note linked to the active page. Each note can include a title, Markdown body, tags, an optional page URL, and an optional workspace association.

The editor supports common Markdown patterns for headings, emphasis, lists, quotes, links, and fenced code. Vast renders a local preview beside the editor. Undo and redo history is kept for the current editing session.

## Organize the notebook

You can:

- search titles, bodies, tags, and linked URLs;
- pin important notes to the top;
- mark notes as favorites;
- add comma-separated tags and filter by tag;
- archive notes without deleting them;
- link a note to the active page.

Deleting a note offers a short undo action. Archived notes stay in the local profile until you delete them.

## Side panel notes

The side panel provides a compact note view for the active workspace or page. Use the full Notes page when you need search, tags, Markdown preview, archives, or broader organization.

## Export

Export an individual note as a Markdown (`.md`) file. Notes are also included in Vast's normal local backup and migration workflows.

Vast does not send note text to a remote service by default.
