Vast includes several built-in tools that work with local browser data.

## [Notes](/tools/notes/)

The local notebook supports:

* full-page note editing;
* search;
* tags;
* pinning;
* favorites;
* archive state;
* linking a note to a web page;
* workspace association;
* Markdown-style preview;
* local undo and redo history;
* quote and page-linked workflows;
* export-oriented local storage.

Notes are explicit user-created content. Vast does not send note text to a remote service by default.

## Reading List

Save pages for later without turning them into permanent bookmarks. Reading List items can store title, URL, favicon, excerpt, read state, and workspace association.

## History

History stores local visit information such as page title, URL, visit count, last visit time, and optional workspace association.

History can be cleared manually or disabled globally.

## Recently Closed

Recently Closed lets you reopen recently closed tabs unless that history is disabled in Privacy settings.

## Downloads

Vast tracks local download state, progress, filename, source URL, save path, and security status where available. Downloads may be paused, resumed, opened, or revealed in the file manager depending on platform support.

## To-do

The New Tab dashboard includes lightweight local todo items that can be scoped to a workspace.

## [Session Timeline](/tools/session-timeline/)

Session Timeline stores local snapshots of workspace tab state. Snapshots can be manual or created around major context changes such as workspace switching and restore operations.

Restoring a snapshot replaces the target workspace tab set and creates a safety snapshot first.

## [PDF viewer](/tools/pdf-viewer/)

Vast includes a local PDF surface for local files and supported web documents, including authenticated documents in their originating workspace, with search, page navigation, zoom, rotation, layout controls, document information, and permission-aware copy, print, and download actions.
