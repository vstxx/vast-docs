The sidebar keeps local browser tools available without forcing you away from the current page.

## Panel views

The panel can show:

* Notes
* Bookmarks
* History
* Downloads
* Reading List

Vast remembers relevant panel state as part of the local profile and can remember site-oriented UI context where applicable.

## Sidebar modes

**Unpinned** docks the sidebar beside the page. Use the pin control beside the title to switch to **Pinned over page**, which floats above page content and can be dragged. Its position is saved locally and kept below the browser chrome. Settings also offers Auto mode.

Toggle visibility with the button beside the address bar or Ctrl/Cmd+B.

You can configure panel width and whether labels are displayed.

## Focus Mode

Focus Mode reduces browser-chrome distraction for reading or concentrated work. It changes Vast's surrounding UI rather than granting the website any additional capability.

Automation can toggle Focus Mode as one of its constrained local actions.

## Downloads and Dim mode in 0.3.0

The Downloads panel recovers active progress after an interface reload and retains persistent-session history. Notes and adjacent surfaces follow Dim mode consistently. These panels share the browser's global corner radius; see [History & Downloads](/using-vast/history-and-downloads/) and [Appearance Reference](/customization/appearance-reference/).
