New Tab can be minimal or function as a local dashboard.

## Modes

**Search** shows Vast branding, local clock, search, and optional quick links.

**Vast dashboard** adds configurable local cards and workspace context.

**Blank** shows an empty page with no dashboard content.

## Dashboard sections

You can independently enable:

* Quick Links
* Recent Pages
* Bookmarks
* To-do
* Notes
* Recently Closed
* Workspace Summary
* Session Timeline

Cards can also use a compact layout.

## Quick Links

Quick Links are locally stored shortcuts. You can add, edit, remove, recolor, and reorder them.

A clean profile begins with a small neutral set rather than a large promotional grid.

## Workspace context

The dashboard can show how many tabs and active notes exist in the current workspace and lets you switch workspaces directly.

## Search behavior

Search from New Tab uses the same address-resolution behavior and default search engine as the main address bar.
