---
title: "Bookmarks & Reading List"
description: "Organize durable bookmarks and keep a separate local queue of pages to revisit."
---

Vast provides two different ways to save a page: Bookmarks for durable organization and Reading List for things you intend to return to.

## Bookmarks

A bookmark can store:

* title;
* URL;
* favicon;
* folder;
* optional workspace association;
* creation and update time.

### Folders

Bookmark folders support hierarchy and ordering. Use them when the collection itself matters — for example, projects, research areas, tools, or recurring destinations.

### Bookmarks bar

The bookmarks bar can be:

* hidden;
* always visible;
* visible only on New Tab.

### Side panel and Command Palette

Bookmarks are available from the side panel and are searchable from the Command Palette. Opening a bookmark from a fresh New Tab can reuse that tab instead of creating unnecessary tab clutter.

## Reading List

A Reading List item can contain a title, URL, favicon, excerpt, read state, workspace association, and timestamps.

Use Reading List when the important question is **“Have I come back to this yet?”**, not **“Where should this permanently live?”**

Pages can be saved to Reading List directly from browser actions and from supported macros.

## Local-first behavior

Bookmarks and Reading List are part of Vast's local profile data and are included in normal data export/backup workflows.
