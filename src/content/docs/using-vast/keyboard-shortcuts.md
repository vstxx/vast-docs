title: "Keyboard Shortcuts"

Vast shortcuts are editable in **Settings → Shortcuts**. The defaults are designed to match familiar browser conventions where possible.

| Action            | Default            |
| ----------------- | ------------------ |
| Command Palette   | `Ctrl/Cmd+K`       |
| Focus address bar | `Ctrl/Cmd+L`       |
| New tab           | `Ctrl/Cmd+T`       |
| Close tab         | `Ctrl/Cmd+W`       |
| Reload            | `Ctrl/Cmd+R`       |
| Reopen closed tab | `Ctrl/Cmd+Shift+T` |
| Toggle sidebar    | `Ctrl/Cmd+B`       |
| Find in page      | `Ctrl/Cmd+F`       |
| Back              | `Alt+Left`         |
| Forward           | `Alt+Right`        |
| Zoom in           | `Ctrl/Cmd+Plus`    |
| Zoom out          | `Ctrl/Cmd+Minus`   |
| Reset zoom        | `Ctrl/Cmd+0`       |
| Print             | `Ctrl/Cmd+P`       |
| Toggle ad blocker | `Ctrl/Cmd+Shift+A` |

## Editing shortcuts

Vast parses shortcuts into modifier/key combinations and checks the configured bindings rather than treating them as arbitrary labels.

If a custom binding becomes inconvenient, **Reset shortcuts** restores the default map.

:::note
Operating-system shortcuts, accessibility software, keyboard-layout differences, and other applications can claim combinations before Vast receives them. If a custom shortcut does not fire consistently, test a less contested combination.
:::
