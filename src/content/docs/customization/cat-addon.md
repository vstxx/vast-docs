---
title: "Cat Addon"
description: "Status of the retired Cat Addon in current Vast Browser releases."
---

Cat Addon is **not available in Vast 0.3.0**. Its implementation and assets were removed from the browser; there is no current setting that enables it.

Older descriptions of animated cat scenes and text reactions describe retired behavior. This page remains at its previous address so existing links explain the current status.

For supported customization, see [Appearance Reference](/customization/appearance-reference/).
